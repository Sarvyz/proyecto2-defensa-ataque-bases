- Como probar el proyecto:

1. Utilice una version de Python no tan reciente (recomendada y usada para el desarrollo: 3.11.9, 3.12/13 deberian funcionar igual)

2. Instale las librerias dictadas a continuacion (sujeto a cambios):
pillow
pygame

O corra alguno de los siguientes comandos en su cmd (puede variar):

cd "ubicacion del proyecto clonado"

'
pip install -r requirements.txt
o
python -m pip install -r requirements.txt
'

3. Corra main.py

- El proyecto tiene ciertas medidas de seguridad para evitar algun crasheo en caso de archivos faltantes, como sea, no es perfecto, y de todas formas, el proyecto aparecería sin algunas imágenes que podrian ser claves para entender lo que esta sucediendo, por eso, si ocurre algun desperfecto, clone de vuelta los archivos desde github.
